# 宇宙シミュレーター 試作 v0.1（フル3D版）

ブラウザで動く宇宙艦隊シミュレーターの試作です。
設計は**アジャイル方式**で進めており、これは完成品ではなく「触って、変えて、また触る」ための v0.1 です。数値・ルールはすべて調整前提です。

## 技術構成

- **Three.js / WebGL によるフル3D**です。平面(2D)マップではありません。
  - 位置・速度・加速度はすべて3次元ベクトル `(x, y, z)` で計算
  - 重力は3D距離に基づくニュートン重力＋数値積分（半陰的オイラー法）
  - 惑星の軌道には傾斜（軌道傾斜角）と昇交点があり、互いに非同一平面上を周回します
  - 目標艦は傾斜18°の軌道にいるため、黄道面内だけの移動ではランデブーできず、上下方向の推力による軌道面変更が必要です
- 単一HTMLファイル（`index.html`）＋同梱の `three.min.js`（Three.js r128、MITライセンス）のみで動作します。ビルド工程は不要です。
  - `three.min.js` が無い場合は CDN（cdnjs）から自動で読み込むフォールバック付きです
  - Muse 固有の仕組みには依存していません

## ローカルでの動かし方

どちらでも動きます。

1. **ファイルを直接開く**: `index.html` をブラウザで開く（`three.min.js` が同じフォルダに必要です）
2. **簡易サーバーで開く**（推奨）:
   ```bash
   cd space-simulator
   python3 -m http.server 8000
   # ブラウザで http://localhost:8000 を開く
   ```

## 遊び方（v0.1）

- **任務**: 目標艦「あけぼの」とランデブー（ドッキング）すること
  - 成功条件: 3次元距離 12 未満 **かつ** 相対速度 1.5 以下
  - 失敗条件: 距離 7 未満で相対速度 2.0 超のまま接触すると衝突
- **操艦**:
  - `W/S`: 前後（軌道面内）、`A/D`: 左右（軌道面内）
  - `R/F` または `Q/E`: **上下（軌道面の外への推力）** ← 軌道面を変えるのに必須
  - `M`: 目標に相対速度を合わせるバーン（Δvを消費）
  - `Space`: 時間停止／再開、画面ボタンで推力・時間倍率(0/1/3/8x)も変更可
  - 推力を使うと残り Δv（推進剤）が減り、ゼロになると加速できません
- **カメラ**: ドラッグ=回転、ホイール=ズーム、右ドラッグ／Shift+ドラッグ=パン。「自艦追従」ボタンで自艦を追う視点にも切替可能
- **ワープ（恒星間移動）**: 恒星からの距離 340 以上の外縁域でのみ可能。ワープ燃料を消費してソル／ケンタウリ／シリウス／トラピストの4恒星系を移動できます。系内の物理はリアル計算のままです（ワープは恒星間だけの“誤魔化し”）
- **シナリオ（開始ランク）**: 新任艦長（1隻）／戦隊司令（僚艦2隻）／艦隊司令（僚艦4隻＋豊富な資源）で、扱える規模が変わります
- **部下**: 将校4名に役割（戦術・補給・政治・造船など）を割り当て可能。将校たちは定期的に自律的に政治・補給イベントを起こします（イベントログ参照）
- **生産・補給・政治**: 資源は推進剤ストック／補給物資／資金／政治的支持／ワープ燃料。ドッキング中に補給を受けると Δv が全回復。小型艦の建造をキューに入れると時間経過で僚艦が増えます

## 後で公開する方法（Firebase Hosting の概要）

まだデプロイはしていません。公開する段階になったら:

1. Firebase プロジェクトを作成し、CLI を入れる（`npm install -g firebase-tools`、`firebase login`）
2. このフォルダで `firebase init hosting`（公開フォルダはこのフォルダ自身を指定、`index.html` と `three.min.js` がそのまま配信されます）
3. `firebase deploy --only hosting`

オンライン対戦・セーブ共有などのマルチプレイ化は、将来 Firestore / Realtime Database と権威サーバー（Cloud Run 等）を追加する想定です。v0.1 は単独プレイの物理・ゲーム感の検証用です。

## 既知の制限（v0.1）

- 惑星同士の重力相互作用は省略（惑星は恒星重力のみ、自艦・僚艦は恒星＋惑星の重力を受けます）
- 相対論効果（時間の遅れ、光速制限、光の到達遅延）は未実装。次フェーズ候補です
- モバイル: 画面ボタンで推力は出せますが、カメラ操作と情報量の都合上、快適なプレイはデスクトップ推奨です
- セーブ機能はありません（リロードでリセットされます）
